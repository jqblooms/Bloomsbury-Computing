          Pseudocode cheat sheet
          

            
Plants a seed you own where your cursor is standing.

            

            
CALL Sell()Sells a fully grown plant where your cursor is standing, for 1.5× what the on-screen Sell button pays.

            
TRUE if the square has that crop growing. Leave the crop name out to check whether anything is growing there. Also callable as HasPlant(...) - same thing, worded more generally.

            
CropOnTile()

            
Money()How many coins you have right now. E.g. WHILE Money() < 50 DO.

            

            
CALL MoveUp()Moves your cursor one tile up the field.

            
CALL MoveDown()Moves your cursor one tile down the field.

            
CALL MoveLeft()Moves your cursor one tile left.

            
CALL MoveRight()Moves your cursor one tile right.

            
CALL MoveForward()Moves one tile in the direction your cursor is currently facing.

            
CALL TurnLeft()Turns your cursor 90° left, without moving it.

            
CALL TurnRight()Turns your cursor 90° right, without moving it.

            
CALL SetPosition(2, -1)Jumps straight to a tile, counted from home: 2 right, 1 up. Home is (0,0) - the tile you were on when you pressed Run, or the tile a machine was placed on.

            
OUTPUT "hi"Prints a message to the console below.

            
DECLARE Total : INTEGEREvery variable must be declared with its type before it is used, including a FOR loop's counter. Types: INTEGER, REAL, STRING, CHAR, BOOLEAN, or ARRAY[1:5] OF INTEGER for a list.

            
FOR Index <- 1 TO 5
  ...
NEXT Index		Repeats the lines in between, 5 times. No "DO" on a FOR line. Declare Index first.

            
IF X = 1 THEN
  ...
ELSEIF X = 2 THEN
  ...
ELSE
  ...
ENDIF		Runs the first branch with a true condition. ELSE runs if no earlier condition is true.

            
WHILE X < 10 DO
  ...
ENDWHILE		Repeats while the condition is true. Compare with =, <>, <, >, <=, >= and combine with AND, OR, NOT. Either side can be maths too, e.g. WHILE N < Total + 1 DO.

            
X <- X + 1Math uses +, -, *, /, DIV and MOD, with brackets to group. You need this to change a variable inside a WHILE loop, or it runs forever.

          

          
A little white dot on your cursor (or a machine's blue diamond) shows which way it's facing.

          

          
Every machine starts at Level 1 and performs one working instruction per second. Upgrade it through Levels 2 to 9 for the matching number of instructions per second. Level 10 performs 15 instructions per second.

          
IF, ELSEIF, ELSE, ENDIF, FOR, NEXT, WHILE and ENDWHILE control which instruction runs. These control lines do not use an instruction slot.

          
Click a placed machine to select it. Its cursor turns pink and grows. From there you can edit its code, upgrade it, or sell it back for half the total amount spent on it.
