How to play

Code blocks fall from the top. Click one, answer it below, and it disappears. Each wrong answer lowers the ceiling; if a block reaches the ceiling, the game is over.

Syntax error

The code breaks Python's rules, so it will not run. Fix the spelling or the punctuation.

Logic error

The code runs but does the wrong thing. Fix what it does.

Comments

A line starting with # explains the code. Match the comment to the code it describes.

More than one line

Write the comment on one line and the code on the next. Press Enter for a new line.

Several steps

Write a comment and a line of code for each thing the block asks for, in order.

Variables

Store a value with a name, for example name = "Bob" or age = 15.

Power-ups

10 right in a row earns a bomb that clears the blocks where you drop it, 20 earns ice that freezes every block for 30 seconds, and 30 earns a hammer that smashes one block.

Support

Turn Support on to see a model of the answer to type over, or wrong options ruled out. It fades as you get blocks right. It is never used in exams.
