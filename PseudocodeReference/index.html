Variables and Sequence

Every variable is DECLAREd before it is used, with a type. Assignment uses the left-pointing arrow, not an equals sign.

Declare, then assign

DECLARE Age : INTEGER
DECLARE Name : STRING
Age <- 16
Name <- "Aiko"

Input and output

OUTPUT "Enter your age "
INPUT Age
OUTPUT "You are ", Age, " years old"

Every INPUT step should have an OUTPUT prompt directly before it, so the user knows what to type. Combine several values in one OUTPUT with commas.

The main data types

INTEGER   // whole numbers
REAL      // decimals
CHAR      // one character
STRING    // text
BOOLEAN   // TRUE or FALSE

Selection

A decision the program makes while it runs. Always close IF with ENDIF.

IF / THEN / ELSE

IF Age >= 18
  THEN
    OUTPUT "Adult"
  ELSE
    OUTPUT "Minor"
ENDIF

ELSE is optional — leave it out if there is nothing to do when the condition is false.

Combining conditions

IF Age >= 13 AND Age <= 19
  THEN
    OUTPUT "Teenager"
ENDIF

AND, OR and NOT work exactly as in Year 7 flowchart work — both sides of AND must be true, only one side of OR needs to be true.

Iteration

Three loop shapes. Pick the one that matches how many times the loop should run.

FOR — count-controlled (you know how many times in advance)

FOR Index <- 1 TO 10
  OUTPUT Index
NEXT Index

WHILE — pre-condition (checked BEFORE each pass, may run zero times)

INPUT Number
WHILE Number < 1 OR Number > 10 DO
  OUTPUT "Out of range, try again "
  INPUT Number
ENDWHILE

This is the standard validation-loop shape: input once before the loop, test the condition, input again only inside the loop.

REPEAT — post-condition (checked AFTER each pass, always runs at least once)

REPEAT
  OUTPUT "Enter a password (at least 10 characters) "
  INPUT Password
UNTIL LENGTH(Password) >= 10

Notice REPEAT needs no separate INPUT before it — the loop body always runs once, so the first input happens inside the loop.

Common mix-up: WHILE tests its condition and STOPS the loop when the condition becomes true or false depending on how you wrote it — read your own condition back to yourself before submitting. REPEAT...UNTIL keeps going UNTIL the condition becomes TRUE.

Arrays

A fixed collection of values of the same type, accessed by index. Bloomsbury Computing's pseudocode indexes start at 1.

DECLARE Scores : ARRAY[1:30] OF INTEGER
Scores[1] <- 55
FOR Index <- 1 TO 30
  INPUT Scores[Index]
NEXT Index

Before You Submit

  • Every variable DECLAREd before it is assigned or read.
  • Every IF has a matching ENDIF; every FOR has a matching NEXT; every WHILE has a matching ENDWHILE.
  • Every INPUT has an OUTPUT prompt just before it explaining what to type.
  • Read your own condition back to front — does the loop actually stop when you think it does?
  • Indent the lines inside IF, FOR, WHILE and REPEAT so the structure is easy to read.
